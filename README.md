# GlassesPlayer

macOS 视频播放器，专为 VR 智能眼镜和 360° 全景视频设计。

## 功能特点

**立体视觉支持**
- 左右并排 (Side-by-Side) 和上下并排 (Top-Bottom) 两种立体布局
- 左眼 / 右眼 / 双眼 三种显示模式，适配不同眼镜硬件

**360° 全景播放**
- 等距柱状投影 (Equirectangular) 全景视频
- 鼠标控制视角，全屏模式下光标自动换边，无缝环视
- 拖拽模式和指针模式两种交互方式
- 滚轮缩放 FOV（视场角），支持 60°~150° 调节

**Metal 渲染管线**
- 基于 Apple Metal 的 GPU 加速渲染
- 通过 IOSurface 桥接 mpv (OpenGL) 和 Metal
- 60fps 流畅播放，低延迟视角响应

**HLS 录制修复**
- 自动检测并修复 HLS 直播录制产生的 MP4 时间轴错误
- 原始文件不会被修改，使用 APFS COW 克隆 + 原子修补
- 无需手动操作，打开即修复

**播放控制**
- 逐帧前进 / 后退，精准定位画面
- 自动扫描同目录视频，支持上一集 / 下一集切换
- 播放模式：播完停止 / 单曲循环 / 列表播放 / 列表循环
- 可调倍速：1× ~ 3×
- 滚轮调节音量（按住 Option 键时）
- 拖拽文件到窗口直接打开播放

## 键盘快捷键

| 按键 | 功能 |
|------|------|
| `Space` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `,` / `<` | 上一帧 |
| `.` / `>` | 下一帧 |
| 双击 | 全屏 / 退出全屏 |
| 右键 | 显示 / 隐藏控制栏 |

## 系统要求

- macOS 14.0+
- Apple Silicon (arm64)
- 支持格式：MP4, MKV, MOV, AVI, M4V, WebM 等（mpv 支持的所有格式）

## 下载与安装

1. 前往 [Releases](../../releases) 下载最新版本
2. 将 `GlassesPlayer.app` 拖入 Applications 文件夹
3. 首次打开如遇"无法验证开发者"，前往 系统设置 → 隐私与安全性 → 点击"仍要打开"

## 使用说明

1. 点击文件夹图标或拖拽视频文件打开
2. 点击立体图标打开 Source & Display 面板，选择视频布局（SBS / TB / 360°）
3. 选择显示模式（左眼 / 右眼 / 双眼）
4. 用滚轮缩放视角，鼠标移动控制视角方向
